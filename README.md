# HDIIA Critical Infrastructure Security Assessment

## Project Overview

HDIIA Critical Infrastructure Security Assessment is a cybersecurity
portfolio project demonstrating a complete security assessment lifecycle
and target security architecture development.

The project follows a risk-driven methodology connecting business
requirements with technical security controls.

------------------------------------------------------------------------

## Security Assessment Methodology

The assessment follows:

Business Context

↓

Critical Services

↓

Assets

↓

Dependencies

↓

Threats

↓

Risks

↓

Security Controls

↓

Target Architecture

↓

Security Improvement Roadmap

------------------------------------------------------------------------

## Project Objectives

-   Identify critical assets and dependencies
-   Analyze cyber threats and risks
-   Map security controls to recognized frameworks
-   Design a target security architecture
-   Create an implementation roadmap
