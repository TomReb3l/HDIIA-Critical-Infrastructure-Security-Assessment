# Ελληνική Έκδοση

## 1. Σκοπός

Το Security Maturity Target Model καθορίζει το επιθυμητό επίπεδο
ωριμότητας μετά την εφαρμογή των προτεινόμενων βελτιώσεων.

Βασίζεται στο:

-   Current State Assessment
-   Maturity Assessment Model
-   Security Gap Analysis
-   Improvement Roadmap

------------------------------------------------------------------------

# 2. Current vs Target Maturity

  Security Domain       Current Level        Target Level
  --------------------- -------------------- -----------------
  Governance            Level 3 Defined      Level 4 Managed
  Asset Management      Level 3 Defined      Level 4 Managed
  Identity Security     Level 2 Developing   Level 4 Managed
  Network Security      Level 3 Defined      Level 4 Managed
  Security Monitoring   Level 2 Developing   Level 4 Managed
  Incident Response     Level 2 Developing   Level 4 Managed
  Resilience            Level 3 Defined      Level 4 Managed

------------------------------------------------------------------------

# 3. Target Maturity Characteristics

## Level 4 --- Managed

Χαρακτηριστικά:

-   μετρήσιμες security διαδικασίες
-   ενεργή παρακολούθηση
-   risk-based αποφάσεις
-   επαναλαμβανόμενες διαδικασίες βελτίωσης

------------------------------------------------------------------------

# 4. Strategic Maturity Objectives

## Identity

Στόχος:

Ώριμη διαχείριση ταυτοτήτων με MFA και PAM.

## Network

Στόχος:

Segmented και monitored network architecture.

## Monitoring

Στόχος:

SIEM-based detection capability.

## Resilience

Στόχος:

Ελεγμένες διαδικασίες ανάκαμψης.
