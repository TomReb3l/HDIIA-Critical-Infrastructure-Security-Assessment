# Ελληνική Έκδοση

## 1. Σκοπός

Το Security Metrics Framework καθορίζει μετρήσιμους δείκτες για την
παρακολούθηση της βελτίωσης της security maturity.

Οι metrics συνδέονται με:

-   Risk Register
-   Security Controls
-   Target Architecture
-   Improvement Roadmap

------------------------------------------------------------------------
