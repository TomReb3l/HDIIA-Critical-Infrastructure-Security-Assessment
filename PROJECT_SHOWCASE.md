# 1. Project Overview

The HDIIA Critical Infrastructure Security Assessment is a cybersecurity
portfolio project demonstrating an end-to-end risk-based security
assessment lifecycle for a fictional critical infrastructure
organization.

The project follows a structured approach to identify security risks,
evaluate their impact, map security controls, design a target security
architecture, and define an improvement roadmap.

---

# 2. Business Problem

Critical infrastructure environments require security approaches that
protect:

-   Business-critical services
-   Supporting assets
-   Operational dependencies
-   Sensitive information
-   Service availability and resilience

---

# 3. Assessment Approach

The project follows:

Threat Modeling

↓

Risk Assessment

↓

Security Control Mapping

↓

Target Security Architecture

↓

Security Improvement Roadmap

Each phase maintains traceability between risks, controls, architecture
decisions and improvement actions.
