# Contributing Guidelines

Thank you for contributing to the HDIIA Critical Infrastructure Security
Assessment project.

## Project Principles

All contributions should maintain:

-   Clear cybersecurity methodology
-   Traceability between risks, controls and architecture
-   Consistent documentation structure
-   Professional security assessment practices

## Repository Structure

Follow the existing phase structure:

-   05 Risk Assessment
-   06 Security Control Mapping
-   07 Target Security Architecture
-   08 Security Improvement Roadmap

## Documentation Standards

Changes should:

-   Include clear purpose and scope.
-   Maintain version information.
-   Preserve assessment traceability.
-   Avoid unsupported compliance claims.

## Pull Requests

Pull requests should include:

-   Description of changes
-   Reason for modification
-   Impact on related artifacts

## Security Considerations

Do not include:

-   Real credentials
-   Sensitive information
-   Production data
-   Confidential organizational details

All examples should remain fictional or sanitized.
