# Ελληνική Έκδοση

## 1. Σκοπός

Το Maturity Assessment Model αξιολογεί το τρέχον επίπεδο ωριμότητας ασφάλειας του HDIIA και καθορίζει την απόσταση μεταξύ της υφιστάμενης κατάστασης και της επιθυμητής Security Architecture.

Η αξιολόγηση βασίζεται στην παραδοχή:

**Το HDIIA διαθέτει βασικές security capabilities αλλά χρειάζεται μετάβαση σε mature security architecture.**

---

# 2. Maturity Model

Χρησιμοποιείται κλίμακα πέντε επιπέδων:

| Level | Description |
|---|---|
| Level 1 - Initial | Αποσπασματικές διαδικασίες, περιορισμένα controls |
| Level 2 - Developing | Υπάρχουν βασικές δυνατότητες αλλά χωρίς πλήρη συνέπεια |
| Level 3 - Defined | Καθορισμένες διαδικασίες και βασικά security practices |
| Level 4 - Managed | Μετρήσιμη, ελεγχόμενη και βελτιστοποιημένη λειτουργία |
| Level 5 - Optimized | Συνεχής βελτίωση και προηγμένες δυνατότητες |

---

# 3. Current Security Maturity Assessment

| Security Domain | Current Level | Target Level | Observation |
|---|---|---|---|
| Security Governance | Level 3 - Defined | Level 4 - Managed | Υπάρχουν βασικές διαδικασίες αλλά απαιτείται μεγαλύτερη μέτρηση |
| Asset Management | Level 3 - Defined | Level 4 - Managed | Υπάρχει inventory και dependency mapping |
| Identity Security | Level 2 - Developing | Level 4 - Managed | Απαιτείται MFA και PAM maturity |
| Network Security | Level 3 - Defined | Level 4 - Managed | Απαιτείται ενίσχυση segmentation |
| Security Monitoring | Level 2 - Developing | Level 4 - Managed | Απαιτούνται SIEM και detection capabilities |
| Incident Response | Level 2 - Developing | Level 4 - Managed | Απαιτούνται ώριμες διαδικασίες απόκρισης |
| Resilience & Recovery | Level 3 - Defined | Level 4 - Managed | Απαιτείται βελτίωση recovery testing |

---

# 4. Maturity Gap Summary

Κύρια gaps:

- περιορισμένη αυτοματοποίηση security operations
- ανεπαρκής ωριμότητα identity protection
- ανάγκη ενίσχυσης monitoring
- ανάγκη καλύτερης μέτρησης security performance
- ανάγκη συνεχούς βελτίωσης resilience

---

# 5. Improvement Direction

Η μετάβαση στο Target State απαιτεί:

- ενίσχυση Zero Trust αρχών
- ανάπτυξη Security Operations capability
- βελτίωση identity governance
- ενίσχυση detection and response
- συνεχή αξιολόγηση κινδύνων

# English Version

## Purpose

The Maturity Assessment Model evaluates HDIIA's current cybersecurity maturity and defines the transition path toward a mature security architecture.

## Maturity Levels

The model uses five levels:

1. Initial
2. Developing
3. Defined
4. Managed
5. Optimized

## Assessment Summary

Current maturity is assessed as intermediate, with improvement needs in:

- Identity Security
- Monitoring
- Incident Response
- Network Segmentation
- Resilience

## Target Objective

Move from defined security capabilities toward managed and measurable security operations.
