# Project Structure Baseline

Version: 1.1

## Purpose

Το έγγραφο καθορίζει την επίσημη δομή repository και τη σχέση μεταξύ
phases και artifacts.

Η βασική λογική είναι:

``` text
Risk
 ↓
Controls
 ↓
Architecture
 ↓
Roadmap
```

## Repository Structure

``` text
HDIIA-Critical-Infrastructure-Security-Assessment

├── 00_Project_Governance
├── 01_Business_Context
├── 02_Current_State_Assessment
├── 03_Asset_Management
├── 04_Threat_Model
├── 05_Risk_Assessment
├── 06_Security_Control_Mapping
├── 07_Target_Security_Architecture
├── 08_Security_Improvement_Roadmap
├── 09_Interview_Preparation
├── 10_Final_Report
├── diagrams
├── README.md
└── README_GR.md
```

## Phase Mapping

05 Risk Assessment: Risk identification, scoring and prioritization.

06 Security Control Mapping: Mapping risks to required security
controls.

07 Target Security Architecture: Design of future-state security
architecture.

08 Security Improvement Roadmap: Implementation planning and security
metrics.
